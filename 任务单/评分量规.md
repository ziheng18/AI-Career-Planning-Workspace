# 教师评分量规

**课程：** 职业生涯规划　**对象：** 人工智能专业本科生
**总分：** 100 分　**评阅依据：** 学生提交的《职业生涯规划报告》+ 档案 JSON

## 一、评分总览

| 维度 | 分值 | 对应交付物 | 可核查位置 |
|---|---|---|---|
| A 完成度与规范性 | 15 | 报告 + 档案 JSON | 报告目录、档案字段完整性 |
| B 数据质量 | 15 | 档案 JSON | `answers` 的作答分布、时间戳 |
| C 自我认知的深度 | 20 | 报告第一、五章 | 兴趣/锚/能力解读、SWOT |
| D 行业认知的真实性 | 20 | 报告第二章 + 职业简表 | 岗位分析、工作内容占比的解读 |
| E 决策与路径的逻辑性 | 15 | 报告第三章 | 权重设置、路径比较、Plan B |
| F 行动计划的可执行性 | 15 | 报告第五章 | 任务、截止日、验收证据 |

---

## 二、分维度细则

### A 完成度与规范性（15 分）

| 得分 | 标准 |
|---|---|
| 13–15 | 8 项任务全部完成；报告结构完整（五章 + 附录）；档案 JSON 完整可导入；有数据性质声明 |
| 9–12 | 完成 6–7 项；报告结构基本完整，个别章节单薄 |
| 5–8 | 完成 4–5 项；报告有明显缺章 |
| 0–4 | 完成 ≤3 项；无档案 JSON 或无法导入 |

**核查方法**：用工作台的「导入档案 JSON」功能加载学生档案，页面「导出报告」页会显示完整性与缺失清单。

### B 数据质量（15 分）

| 得分 | 标准 |
|---|---|
| 13–15 | 无质量告警；或出现告警但学生在报告中作出了合理解释/已重做 |
| 9–12 | 出现 1–2 项告警，学生未说明但影响有限 |
| 5–8 | 出现多项"作答过于集中"或"疑似快速作答"告警，明显影响结果可信度 |
| 0–4 | 大面积直线作答（如正向题全 4、反向题全 2），测评数据实际无效 |

**核查方法**：
- 结果页「我的画像」标签顶部的**数据质量提示**区；
- 档案 JSON 中 `answers.*.*.t` 时间戳的跨度 ÷ 题数 = 每题平均秒数（< 3 秒即告警）。

> **这是本量规中最需要实际打开档案核查的一项。** 只读报告文字无法发现直线作答。

### C 自我认知的深度（20 分）

| 得分 | 标准 |
|---|---|
| 17–20 | 不只是抄录测评结论，而是**用自己的语言解释矛盾点**（例如"我的兴趣指向研究，但职业锚是管理型，这解释了我为什么既想做深又坐不住"）；SWOT 经过个人化改写，有具体事例 |
| 13–16 | 对测评结论有解读，但偏描述性；SWOT 部分照搬系统生成内容 |
| 8–12 | 基本是测评结果的复述 |
| 0–7 | 仅有分数罗列，无任何解读 |

**加分观察点**：
- 是否主动指出了测评的局限或与自我认知不一致之处；
- 是否结合了他人评价（老师、同学、家人）来校验自评。

### D 行业认知的真实性（20 分）

| 得分 | 标准 |
|---|---|
| 17–20 | 不只是转述职业简表，而是**对工作内容占比做出了自己的判断**（例如"我发现这个岗位一周有 40% 在写文档，我原本以为技术岗整天写代码，这一点需要重新考虑"）；能把行业结论与自身条件挂钩，指出具体的不匹配之处 |
| 13–16 | 有岗位分析，但基本是对报告内容的复述，缺少"这对我意味着什么" |
| 8–12 | 只抄录了岗位职责，没有涉及工作内容分配或风险 |
| 0–7 | 未阅读/未使用职业简表，第二章内容空泛或与本人偏好明显无关 |

**核查方法**：
- 报告第二章的「职业简表」里，**「一周工作内容占比」一栏是本课程的核心材料**。看学生是否对这一栏作出了反应：有人会发现技术岗并非整天写代码，有人会发现自己排斥的正是这个岗位的主要工作内容。**有反应就是好的**，无论最后决定继续还是换方向。
- 是否把「这个岗位的风险」与自己能接受的程度联系起来，而不是抄一遍。

> **v0.2 变更说明**：原要求的「生涯人物访谈 2 位」已取消。理由：访谈时间成本高，且学生不一定能找到合适的从业者，作为必做作业不合理。原来由访谈承担的两项判断（这份工作实际在做什么、实际代价是什么）改由报告自动生成的**职业简表**承担。如果学生**自愿**完成了访谈，请写进报告正文，并在本维度加分。

### E 决策与路径的逻辑性（15 分）

| 得分 | 标准 |
|---|---|
| 13–15 | 更看重兴趣、成长等长期指标，且与其陈述的价值观一致；路径评分有改动且改动有理由；报告解释了主路径与 Plan B 的分工，以及"什么情况下我会切到 Plan B" |
| 9–12 | 排序与评分基本合理，但缺少切换条件的说明 |
| 5–8 | 直接使用系统预填的参考评分，未体现个人判断 |
| 0–4 | 权重与偏好明显矛盾（例如声称最看重生活平衡，却把 balance 排最后） |

> 工作台会自动做**一致性检查**：若学生在最重要标准上打分最高的路径不是加权总分第一，结果页会给出提示。**看学生有没有对这条提示作出回应**，是评阅这一维度的快捷入口。

**大一学生的额外观察点**：是否认同"以兴趣定方向"的处理方式。如果他写下了不认同的理由（例如"我明确知道自己对研究没兴趣，更想尽早做工程"），这属于**加分项**——那正是这门课要培养的判断力。

### F 行动计划的可执行性（15 分）

| 得分 | 标准 |
|---|---|
| 13–15 | ≥8 条任务；每条有明确截止日与**可检查的验收作品**；工时估算与现实时间匹配；已开始执行（有进度或复盘记录） |
| 9–12 | 任务较明确，个别缺验收标准 |
| 5–8 | 任务笼统（如"多学算法"），无验收标准 |
| 0–4 | 无行动计划或仅有愿望清单 |

**核查方法**：看是否有**已完成**的任务与复盘记录。全部停留在"待做"的计划，按 9–12 分以下计。

## 三、扣分项（可叠加，最多扣 15 分）

| 项目 | 扣分 | 说明 |
|---|---|---|
| 篡改测评数据 | −10 | 档案 JSON 明显为手工构造而非界面作答（如全部题同一时间戳） |
| 未提交档案 JSON | −5 | 无法核查数据质量 |
| 报告与档案数据不一致 | −5 | 报告中引用的分数与档案计算结果不符 |
| 未保留数据性质声明 | −3 | 未说明岗位库为示例数据、测评为课程自编 |

---

## 四、评阅流程建议（约 8 分钟／份）

1. **导入档案 JSON**（30 秒）→ 看完整性清单与数据质量提示。
2. **跳转「结果与画像」→「岗位匹配」**（1 分钟）→ 看学生首位岗位与置信度提示。
3. **看报告 T6 要求的结果核查记录**（2 分钟）→ 手算复核过程是否真实。
4. **看报告第二章的职业简表解读**（2 分钟）→ 是否对工作内容占比作出了反应。
5. **看「行动计划」页**（1.5 分钟）→ 有无已完成项。
6. **对照维度 C/E**（1 分钟）→ 尤其看一致性提示的回应。

---

## 五、给评阅者的提醒

- **不要用适配度分数高低评分。** 一个学生首位岗位是"算法研究员"、另一个是"AI 解决方案"，分数高低不反映优劣。评分看的是**推理过程与数据质量**。
- **"双锚"与"前两名接近"不是问题**，而是真实状态。学生如实呈现应加分，不应扣分。
- **允许学生对结果提出反对**。若学生在报告中论证"系统推荐不合理，理由是……"，且论证有理有据，应在 C/E 维度给高分——这正是这门课要培养的判断力。
