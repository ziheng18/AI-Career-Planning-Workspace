活动标签：修白字透明底，并按主题给两套配色

问题：浅色模式下结果页标签栏的活动标签看不见，只剩一个白色药丸。

根因是 CSS 特异性算错，不是颜色值写错：
  .btn-primary        { background: var(--brand); color: #fff }   ← 1 个类
  .result-tabs .btn   { background: transparent }                 ← 2 个类，胜出
前者只被压掉了 background，color 保留了，于是白字落在透明底上——
外层 .result-tabs 是白底，看起来就是白字白底、整条标签隐形。

修法：把活动标签的样式写全，别再依赖 .btn-primary 的默认值。
并按主题分两套（深色那套来自实际观感反馈）：

  浅色：背景 --surface(白) + 文字 --brand-ink(深青绿) + 青绿阴影
        对比度 7.95，活动标签靠阴影"浮起"
  深色：背景 --brand(亮青绿) + 文字 #0d1218(深色)
        对比度 10.10，与容器底(rgb(22,28,36))相差 9.20，明显浮出

深色为什么必须用深色字：亮青绿 #2dd4bf 配白字对比度只有 1.86，
配 --brand-ink(#99f6e4) 更差(1.48)。而 --brand-ink 是给"深底浅字"用的，
这里的底是亮青绿，所以文字色写死深色，不能复用变量。

浏览器诊断新增 6 项断言。其中对比度那条一开始写成弱断言：
背景透明时把 rgba(0,0,0,0) 当黑色算，白字白底反而得出 21.00 的假高分。
改成按祖先链合成出实际可见底色再算——bug 版现在正确报 1.00 FAIL。
验证过：bug 版 FAIL 3 项，修复版全 PASS。

测试 107 + 88，浏览器诊断 19 项。
